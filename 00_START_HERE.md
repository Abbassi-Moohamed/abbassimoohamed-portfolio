## 💡 Key Customization Points

### Easy Changes (No Code)
- Update dialogue messages → Edit `src/index.html`
- Update project descriptions → Edit section files in `src/javascript/World/Sections/`
- Change styling → Edit `src/style/main.css`

### Medium Changes (Requires Design)
- Replace car model → Create new GLB file, place in `static/models/car/`
- Add project models → Create GLB files, add references to `Resources.js`
- Update favicon → Generate new favicon files

### Advanced Changes (Requires Programming)
- Add new features → Edit `src/javascript/World/` components
- Custom shaders → Edit files in `src/shaders/`
- Physics tweaks → Edit `src/javascript/World/Physics.js`
