## ❓ Common Questions

**Q: How do I add my projects?**
A: Edit files in `src/javascript/World/Sections/` and add models to `static/models/`

**Q: Can I change the car?**
A: Yes! Replace models in `static/models/car/default/` or create new ones

**Q: How do I add more content?**
A: Edit `src/javascript/Resources.js` to load new models and `src/javascript/World/Sections/` to add content

**Q: Will it work on mobile?**
A: Yes! Touch controls auto-enable on first touch

**Q: Can I remove the chat bubble?**
A: Yes, set `threejsJourneyPrevent` in localStorage or modify `src/javascript/ThreejsJourney.js`
